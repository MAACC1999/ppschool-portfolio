# Visual Evidence Index

The visuals use three evidence classes. Live captures are labelled with their observation date. Historical captures are retained only when their source documentation identifies them as demonstration or in-memory states. Diagrams are explanatory summaries derived from the public evidence map and linked repository contracts.
